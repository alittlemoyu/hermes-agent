Scope

Read This First

  • 不要把官方 OpenViking LangChain/LangGraph tool aliases 直接加进 Hermes；继续使用 Hermes 当前工具面。
  • 不要在这一层实现 LangGraph Store/KV durable state；它是下一层能力，应该单独设计。
  • 不要持久化 runtime/system policy 文本；只捕获真实 user、assistant、tool、context parts。
  • 合并主线时优先保护当前 OpenViking 补丁层，不要整包回滚已有本地改动。

Files That Define The Boundary

  • agent/memory_provider.py: sync_turn(..., messages=None) 是兼容式扩展。
  • agent/memory_manager.py: sync_all 用 inspect.signature 只给支持的 provider 传 messages。
  • run_agent.py: 完成 turn 后把 conversation_history=list(messages) 传给 external memory sync。
  • plugins/memory/openviking/__init__.py: OpenViking provider 的 context assembly、capture、commit、archive 工具都在这里。
  • tests/plugins/memory/test_openviking_provider.py: fake-client 单测覆盖核心 lifecycle。
  • tests/openviking_plugin/test_openviking.py: 插件注册和工具行为回归。
  • tools/approval.py: 远程 admin/destructive tool action approval 的 fail-closed 通道。

OpenViking Official Patterns We Mirrored

  • <openviking_context>...</openviking_context> 是自动注入 marker；旧的 <relevant-memories> 只作为清理兼容。
  • Session context 优先读取 /api/v1/sessions/{session_id}/context 的 latest_archive_overview、pre_archive_abstracts 和可选 active messages。
  • Recall 命中作为 ContextPart 记录，assistant capture 后通过 /used 回传真实使用痕迹。
  • Assistant tool calls 和 tool results 使用 ToolPart，避免恢复历史时重复触发 assistant tool call。
  • Commit policy 内部支持 never、always、pending_tokens，默认仍是 pending-token threshold。
  • Pending-token commit 查询 session 时不自动创建 session；缺失或查询失败时跳过并 debug 记录。
  • Archive search 先 grep viking://session/{session_id}/history，无命中时 fallback 到 assembled context sections。

Merge Workflow For Future Updates

  1. Run git status --short --branch and note whether OpenViking files are dirty.
  2. Create a patch backup: git diff --binary > /tmp/hermes-openviking-before-main-merge.patch.
  3. Stash dirty changes with a descriptive name if needed.
  4. Fetch and merge origin/main.
  5. Restore stash and resolve conflicts by preserving Hermes local OpenViking lifecycle behavior unless upstream has an equivalent or better implementation.
  6. Re-run the verification suite below before committing or reporting readiness.

Known Caveats

  • 当前工作树中已有更宽的 OpenViking 工具扩展，例如 viking_fs、viking_add_skill、viking_admin。它们不是官方 alias 迁移，不要把它们和 LangChain/LangGraph 兼容别名混为一谈。
  • 如果 upstream Hermes 后续也扩展了 MemoryProvider.sync_turn，需要优先对齐 upstream 参数名和语义，再保留 OpenViking 的 structured capture。
  • 如果 upstream OpenViking REST API 改了 session context 或 archive payload shape，先改 fake-client 测试，再改 provider。
  • 不要因为 archive fallback 能本地匹配，就跳过 raw history grep；grep-first 是为了保留更精确的 server-side history search。
